Purpose

Get Greta into the game as a selectable, visible character. Same pipeline as Aldric's BOM-110, with one deliberate difference: no team colour tinting. Her palette is fixed. Ally and enemy are distinguished only by the HP bar above the head — green for ally, red for enemy.

Import Steve's model, set up the humanoid rig so Mixamo animations retarget onto it in B3. Scale to match Aldric's footprint so neither clips the existing map collision. Greta is ~1.75 m against Aldric's ~1.95 m — the height difference should read on screen.
