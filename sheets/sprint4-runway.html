Block 3 · 2h · the important one

The scope cut

72 issues, two developers, one sprint. That is 36 each. It will not happen, and a sprint everyone knows is impossible stops being a plan.

Do it in this order, because the order is what makes it work:

  • Write the sprint goal first. One sentence, no "and". Something like: "Two characters with real kits, and combat that feels like it lands."
  • Sort every issue against that sentence. Serves it directly → in. Would be nice → backlog. Doesn't serve it → backlog, no argument.
  • Then check the gates. Anything waiting on a Steve delivery that has not arrived cannot be in the sprint. That is not pessimism, it is arithmetic.
What the dependency graph already tells you

BOM-112 blocks six tickets and is the first thing Leon should touch. BOM-129, 130 and 131 each unblock frontend work that cannot start without them. The whole Greta epic sits behind BOM-113. If that art is not in hand by Sunday, Greta is not a Sprint 4 character and the goal sentence needs rewriting.

The honest version of this sprint is probably the combat layer, the event streams, hit feel, and either Greta or the endings-and-auth rollover — not both.
