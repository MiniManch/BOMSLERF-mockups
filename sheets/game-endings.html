Sprint 3 issues — game structure and endings
NEW-BE1
Backend
Game Config — Tunable Parameters System
Match duration, captures needed to win, knockdown trigger window — all stored as server-side constants that can be changed without a code deploy. Leon implements a config object that feeds all session logic.
NEW-BE2
Backend
Game Timer — 11 Minutes, Server Authoritative
Replace 2:15 timer. Single round of 11:00. Server broadcasts every second. At 0:00 triggers Final Stage if no winner. Parameter: MATCH_DURATION_SECONDS.
NEW-BE3
Backend
Flag Capture Win Condition — 1 Capture (Tunable)
Carrier reaches own base with enemy flag + own flag safe at base = match_over, team wins. CAPTURES_TO_WIN parameter defaults to 1. Server validates, broadcasts winner.
NEW-BE4
Backend
Knockdown Mode — Trigger, Rules, Gas
Both flags away from base for 30s simultaneously → Knockdown. Lock respawns, lock flag drop. First carrier death = match over. If active at 11:00: gas closes in from map edges at 1.5% HP/s. Knockdown overrides Final Stage.
NEW-BE5
Backend
Final Stage at 11:00 — Teleport, Reset, Last Team Standing
At 11:00 if no Knockdown active: teleport all 8 players to stage, full HP, reset all cooldowns (Ultimate locked 8s), expand stage to 13.5×13.5m, instant gas everywhere outside stage. Last team alive wins. Gas covers stage at 12:30 if still tied.
NEW-BE6
Backend
Match Over — Clean Session Reset + Return to Queue
On match_over: broadcast winner + stats + SlerfCoin earned to all clients. Reset session state completely. Players can queue again without restarting app. Fixes BOM-72.
NEW-FE1
Frontend
11-Minute Countdown HUD
MM:SS timer top-center, synced to server. Turns red at 1:00 remaining. On 0:00 shows "TIME'S UP" overlay before Final Stage screen.
NEW-FE2
Frontend
Knockdown Mode Activation Screen
"KNOCKDOWN MODE" full-screen flash on trigger. HUD shifts to show only two carriers' HP bars prominently. Gas visual closing in from edges. Steve to provide design direction.
NEW-FE3
Frontend
Final Stage Transition Screen
"FINAL STAGE" announcement. 3-second countdown freeze. Teleport animation. Stage expands visually. Gas fills rest of map. Steve to provide design direction for this dramatic moment.
